# figuras_AL

### Finalização:
> Na última versão atualizada desta branche, está disponível o código fonte do programa que gera matrizes de quadrados e o arquivo .exe independente da biblioteca que funciona em conputados com *Windows 11*.

> **Importante:** O arquivo Gerador de matrizes.exe só irá funcionar na sua máquina se estiver na mesma pasta que os seus aquivos .dll. Caso contrário, o programa não encontrará os arquivos que foram compilados junto com ele e falhará na execução.
